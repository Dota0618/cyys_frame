# 验证与保存

验证时机、范围和已有结果复用遵循全局《阶段交付与验证规则》。

## 数据与环境

- 直接复用现有开发测试库，允许已有业务数据和业务表；不建隔离库、不清库。
- 连接不可用、存在失败迁移或夹具标识冲突时停止，不删除已有记录。
- 测试机构挂在已有总单位下；清理限于本次夹具，共享菜单恢复原状态。
- 存在实际夹具或迁移冲突时，仅串行执行冲突操作；持久文件保护遵循[构建与运行](project-build.md#产物与文件)。

## 验证入口

- 后端、机构、浏览器及发布命令分别使用 `scripts/verify*.ps1`；参数以现有脚本为准。
- 连接配置由[统一入口](../../scripts/use-test-environment.ps1)加载；默认读取开发配置，支持 `-EnvFile` 和调用环境的连接变量。
- 数据库名不改写，密码从现有变量或凭据文件读取；临时注入的变量在命令结束后恢复。

## 阶段交付与保存

- 版本资料保存在[版本目录](../versions/README.md)，部署材料按[部署说明](../../deploy/README.md)维护。
- 使用本地 Git 保存代码，不另建源码快照。
- 本机配置、凭据、日志和构建产物不提交。
