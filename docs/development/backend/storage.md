# 文件存储与配置切换

## 存储与切换

- 业务通过 `ConfiguredStorage/ObjectStorage` 访问文件，Service 处理归属及权限。
- `cyys.storage.active` 控制新文件写入，已有文件按记录中的配置名及对象键访问。
- 有历史文件的配置保留原位置；迁移先复制校验，再更新引用和清理旧对象。
- 连接、容量和凭据使用部署配置，配置不可用时返回失败。

## 访问与生命周期

- 私有根目录位于公开静态目录之外，对象键由后端生成。
- 文件访问经授权，下载复用 `DownloadResponse`；公开或签名链接需单独授权。
- 上传及续传绑定上传者、机构和摘要，复用现有大小、散列和并发控制。
- 清理只处理登记对象，在用文件不得删除；恢复使用 READY 文件。
- 目录只改变分类；附件经父业务授权，解绑只移除关系并保留源文件归属。

## 已实现

| 能力 | 范围 |
|---|---|
| 存储 | 本地私有目录；S3/OSS 保留配置契约 |
| 下载 | 后端流式输出 |
| 上传默认上限 | 直传 20 MiB、分片 5 MiB、续传 1 GiB |
| 文件管理 | 目录、回收、恢复、永久删除 |
| 附件 | 最多 10 个有序且不重复的文件 ID |
