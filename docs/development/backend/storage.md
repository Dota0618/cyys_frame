# 文件存储与配置切换

## 存储与切换

- 业务通过 `ConfiguredStorage`、`ObjectStorage` 访问文件。
- common 处理存储机制，文件 Service 处理归属、权限、状态和元数据事务。
- `cyys.storage.active` 只决定新文件的写入配置。
- 读取、删除和清理使用文件记录的历史配置名及对象键。
- 仍有历史文件的配置不得删除或改指其他存储位置。
- 历史文件迁移先复制并校验，再更新引用，最后清理旧对象。
- 迁移失败保留重试、回滚和旧对象清理记录。
- 未实现驱动或配置不可用时明确失败，不自动回退。
- 根目录、连接、容量和凭据使用部署配置，不写入通用配置表。
- 密钥不得进入前端、日志、文件元数据或下载链接。

## 访问与生命周期

- 本地根目录由部署预建，放在公开静态目录之外。
- 对象键由后端生成，拒绝客户端路径、越界路径和符号链接。
- 文件访问先校验权限、归属和状态，不提供绕过授权的公开路径。
- 下载通过 `DownloadResponse` 输出安全响应头。
- 新增公开访问或签名链接须明确授权和有效期。
- 物理存储与数据库使用分段提交，失败不得标记成功。
- 上传、合并、取消和清理使用同一文件行锁。
- 分片和合并校验真实大小及 SHA-256，重复已确认操作保持幂等。
- 续传绑定上传者、机构和原文件摘要，每次请求重新授权。
- 清理只处理已登记对象，失败保留状态并延后重试。
- 临时清理保留 READY 主文件，不接管回收站永久删除。
- 永久删除按 `PURGING → 删除对象 → PURGED` 执行。
- 恢复仅接受 READY 文件，并放回默认目录。
- 目录只改变分类，不改变文件授权或物理位置。
- 批量移动、恢复和删除整体校验，任一失败则拒绝整个批次。
- 仍有业务引用的文件不得删除。
- 附件通过父业务授权，绑定和解绑与父业务同事务保存。
- 解除附件关联只移除关系，不删除文件。
- 共享附件分别保存父业务范围和源文件机构，不改变源文件归属。

## 已实现

| 能力 | 当前范围 |
|---|---|
| 驱动 | 本地私有存储；S3/OSS 仅配置契约，尚未接入 |
| 下载 | 后端流式下载；Nginx `X-Accel-Redirect` 尚未启用 |
| 上传默认限制 | 直传 20 MiB、分片 5 MiB、续传 1 GiB |
| 临时任务期限 | 直传 1 小时、续传 7 天 |
| 后台清理默认值 | 启用；间隔 60 秒、每批 25 条、失败后 300 秒重试 |
| 文件管理 | 扁平目录、回收站、恢复和永久删除；删除目录最多处理 1000 条 |
| 业务附件 | 有序文件 ID，最多 10 个且不重复；单位通知和版本更新已接入 |

部署见[部署说明](../../../deploy/README.md)。

## 最小配置

```yaml
cyys:
  storage:
    active: local-main
    profiles:
      local-main:
        driver: local
        root: ${CYYS_FILE_ROOT}
```
