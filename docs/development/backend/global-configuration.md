# 全局参数规则

## 规则

- 全局参数统一存储在 `sys_configure`。
- 全局参数值通过 Redis 缓存读取，Redis 不可用时回源数据库。
- 参数修改提交后失效对应缓存，参数读取不得依赖前端固定值。
- 所有明文新密码至少 8 个字符。
- `FILE_FILES`、`FILE_MEDIA`、`FILE_IMAGES` 使用逗号分隔扩展名。
- `FILE_FILES`、`FILE_MEDIA`、`FILE_IMAGES` 任一有值时，上传文件的最终扩展名必须出现在三者合并后的白名单中；三者都为空时不限制文件类型。
- 文件类型规则同时应用于直传和断点续传；前端选择器同步使用公共配置，后端校验为最终约束。
- 全局参数记录只允许修改，不允许删除；前端不显示删除入口，后端拒绝删除请求。

## 参数

| 参数 | 默认值 | 约束与用途 |
|---|---:|---|
| `SYSTEM_NAME` | `CYYS` | 登录页、主页面左上角和浏览器标签页的系统名称 |
| `SYSTEM_PROVINCE_CODE` | 空 | 设置后只显示该编码地区及其下级 |
| `PWD_STRENGTH` | `0` | 只允许 0、1、2；仅约束个人改密，用户新增、修改及管理员重置不受字母/数字组合要求 |
| `PWD_LOCK_NUM` | `5` | 连续错误锁定次数；0 表示不锁定 |
| `PWD_LOCK_HOUR` | `1` | 锁定时长，单位为小时 |
| `COPYRIGHT_TEXT` | 空 | 页脚版权；为空时使用系统名称和当前年份 |
| `MAINTENANCE_MODE` | `0` | 只允许 0、1；1 时显示维护提示并限制普通账号登录 |
| `PASSWORD_EXPIRE_DAYS` | `0` | 密码有效天数；0 表示永不过期 |
| `FILE_MAX_SIZE_MB` | `20` | 单文件大小上限，单位为 MB |
| `FILE_FILES` | 空 | 普通文件扩展名白名单 |
| `FILE_MEDIA` | 空 | 音频和视频文件扩展名白名单 |
| `FILE_IMAGES` | 空 | 图片文件扩展名白名单 |
| `EXPORT_MAX_ROWS` | `5000` | 单次同步导出行数上限，最大 5000 |
| `AUDIT_RETENTION_DAYS` | `365` | 审计保留天数；0 表示不自动清理，当前未启用后台清理 |
| `CONTACT_PHONE` | 空 | 页脚联系电话；为空时不显示 |
