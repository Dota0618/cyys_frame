# 身份与单位上下文

## 上下文

- 业务从 `ScopeContext.get()` 只读当前身份。
- 机构业务使用 `requireScopeId()`，缺少上下文时拒绝执行。
- 请求参数、请求头和默认机构只表示选择，不代表授权。
- 业务不得自行修改身份、切换机构或补充 OWNER 权限。
- common 通过 `IdentityResolver` 取得身份，不查询 admin 表。
- 请求结束和异常退出时由框架清理上下文。
- 异步任务显式固定操作者和机构，执行时重新授权，结束后清理。
- 维护任务使用受限服务身份，不借用用户令牌或通用业务权限。
- 机构和权限范围遵循[权限规则](data-permission.md)。

## 机构

- 机构树只保留一个实际总单位，其他机构均为其后代。
- 保留总单位名称和 ID，不添加虚拟平台或全部机构节点。
- 总单位不得停用或移动，不得新增第二个根。
- 全系统账号归属实际总单位，不创建虚假成员关系。
- 系统共享内容使用独立维护权限和系统审计。

## 账号与审计

- 审计只记录必要的操作者、机构、时间、结果和原因。
- 密码、令牌和原始请求参数不得写入审计。
- 登录失败的机构由服务端确认，无法确认时留空。
- 失败审计和密码错误计数先提交，再返回认证错误。
- 个人改密验证原密码；管理员重置要求独立权限和全系统数据范围。
- 管理员重置只填写目标新密码，不再次输入管理员密码。
- 密码跨机构共用，不设置固定默认密码或发送明文密码。
- 密码操作复用 `PasswordPolicy`，按固定账号顺序加锁并复核会话指纹。
- 改密使用新 BCrypt 盐，使旧会话失效。
- 个人改密使用 `ACCOUNT_SELF` 审计，管理员重置使用 `PLATFORM_CONTROL`。
- 免选机构仅用于自身身份、改密和退出，不豁免业务权限。
- 仅可信反向代理可提供真实客户端 IP，入口必须覆盖代理头。

## 已实现

- 会话保存在单个 API 进程中，重启后失效。
- 文件临时清理使用受限服务身份。

```java
RequestIdentity identity = ScopeContext.get();
String scopeId = identity.requireScopeId();
```
