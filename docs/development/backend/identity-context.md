# 身份与单位上下文

## 上下文

- 业务从 `ScopeContext.get()` 只读身份，机构业务使用 `requireScopeId()`；机构选择仍须授权。
- common 通过 `IdentityResolver` 取得身份，业务不自行切换身份或补充权限。
- 框架清理请求上下文；异步任务固定操作者和机构，执行时重新授权并清理。
- 维护任务使用受限服务身份；范围见[权限规则](data-permission.md)。

## 机构

- 机构树保留一个实际总单位及其后代，总单位不可停用或移动。
- 账号归属真实机构，系统共享内容使用独立维护权限和审计。

## 账号与审计

- 会话保存在单个 API 进程中，重启后失效。
- 免选机构仅用于自身身份、改密和退出；业务权限照常校验。
- 密码操作复用 `PasswordPolicy`；个人改密验证原密码，管理员重置要求独立权限及全系统范围。
- 密码跨机构共用，使用 BCrypt，变更后使旧会话失效。
- 审计只记录必要的操作者、机构、时间、结果和原因，排除密码、令牌及原始请求参数。
- 登录失败机构由服务端确认，失败审计及错误计数独立提交；客户端 IP 仅信任受控代理。
