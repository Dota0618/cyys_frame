# 功能权限与数据范围

## 功能权限

- Controller 使用 `@SaCheckPermission`，普通 Service 不重复入口鉴权；共用选项用 `SaMode.OR`。
- 切换机构不改变操作权限。
- `SUPER_ADMIN` 可授予全部启用权限，仍受数据范围、机构授权及最后管理员保护约束。

## 数据范围

- 账号统一数据范围取值：0 全系统、1 本机构、2 自定义部门、3 本部门、4 本部门及下级、5 本人、6 本机构及下级；新账号默认本人。
- 自定义部门只包含勾选项；机构树和部门树分别维护。
- 所选机构须在授权范围内，并缩小查询范围；新记录归属所选机构。
- 通用行范围复用 `DataPermissionInterceptor`，只读视图禁止写入。
- 缺少上下文或无法完成范围解析时拒绝执行，业务不绕过拦截器。

## 业务接入

- 模型用 `@DataResourceDefinition` 登记资源，只配置与默认值不同的字段；Mapper 使用 `@ProtectedMapper`。
- 身份、授权、审计及手工限定范围的 Mapper 使用 `@ManualDataScope`，每个 Mapper 只选一种声明。
- 关联查询按各表过滤；部门由 Service 校验并设为不可变，普通业务复用现有范围机制。

## 特殊写入

- 用户资料与数据范围共同保存；修改范围需要 `user:data-permission`，未提交时保留原值。
- 用户授权管理要求所选机构的完整数据范围，授予范围不得超过本人。
- 授权写入沿用保护锁、用户/角色锁及锁后权限检查。
- 共享附件、密码重置和流水号预留沿用各自的条件授权。
