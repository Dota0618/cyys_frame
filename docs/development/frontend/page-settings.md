# 页面设置

## 页面结构

- 页面根节点使用 `PageContainer`，统一设置 `title` 和必要的 `subTitle`。
- 管理页面复用现有布局、表格、表单和弹窗组件。
- 页面业务接口只放在 `src/services/<功能>/`。
- 页面不直接拼接请求地址或调用底层 `fetch`。

## 页面状态

- 页面加载状态使用组件的 `loading` 或 `Spin`，不使用阻塞式全局加载。
- 页面请求失败保留可重试入口，并显示服务端错误消息。
- 组件卸载后不写回状态。
- 机构切换后清除旧列表、筛选和弹窗状态。
- 迟到请求不覆盖新机构或新版本的数据。

## 权限与操作

- 页面入口权限由路由和服务端共同校验。
- 新增、修改、删除和刷新按钮按 `useAccess` 控制显示。
- 隐藏按钮不替代服务端权限校验。
- 删除、批量写入和不可逆操作使用确认组件。
- 并发写入提交版本字段，冲突后提示刷新数据。

## 表格与设置项

- `ProTable` 使用稳定的 `rowKey`，查询字段与服务端参数保持同名。
- 页面不新增重复的机构选择器或切换控件。
- 表格列设置、密度、全屏和刷新按钮按页面需要显式配置。
- 不使用 `localStorage` 保存业务筛选、权限或机构状态。
- 页面自定义设置使用组件状态或已有会话工具，并在卸载时清理。

## 表单与反馈

- 新增和编辑表单分别设置字段、初始值和提交命令。
- 表单字段使用对应 API 命令，不绑定完整持久化实体。
- 表单打开、修改、提交和关闭时维护 `setDirty` 状态。
- 提交失败保留输入内容，不自动重试写请求。
- 成功、失败和版本冲突反馈只在当前页面显示一次。
