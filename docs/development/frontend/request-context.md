# 前端请求与单位切换

- API 统一经过 `src/utils/request.ts`，业务接口放在 `src/services/<功能>/`。
- 页面不直接拼接请求地址或调用底层 `fetch`。
- 请求层只解包一次 `R`，错误统一提示。
- 登录态和机构选择使用 `sessionStorage`，各标签页独立。
- 身份、可选机构和权限使用服务端结果。
- 菜单和按钮可见性不替代服务端授权。
- 路由在 `config/routes.ts` 登记，权限映射放在 `src/access.ts`。
- 机构选择只放在右上角，使用可搜索的实际机构树。
- 页面和弹窗不重复提供机构选择、切换按钮或选择提示。
- 未选定有效机构时，不挂载会发起机构数据请求的内容。
- 通过 `updateSession` 切换身份或机构，清除列表、筛选、弹窗和表单状态并释放订阅。
- 有未保存内容时，确认后再切换。
- 表单和上传组件分别登记、清理自身未完成状态。
- 请求携带上下文版本，过期响应不回填、不提示。
- ProTable 的 `current/pageSize` 映射为 `page/size`。
- 分页响应的 `records/total` 映射为 `data/total/success`。
- 空列表按成功处理，请求失败保留可重试状态。
- 候选接口按操作返回可选数据，保存时由后端重新校验。
- 当前机构失效时，仅身份刷新可重新选择默认机构。
- 业务请求不得自动换机构或重试写入。
- 机构树规则遵循[身份与单位上下文](../backend/identity-context.md)。

## 下载

- 下载复用 `saveDownload` 和 `apiBlob`，携带当前身份与机构。
- 下载结果交给浏览器前复核上下文版本。
- 下载后移除临时元素并延迟释放对象 URL。
- 导出使用已完成查询的筛选条件，并显示导出范围。
