# 表单模型与输入反馈

- 表单字段与对应 API 命令一致，不绑定完整持久化实体。
- 新增和编辑分别设置字段与初始值，不提交只读字段。
- 必填、长度、格式、数值范围和条件字段提供即时提示。
- 提交失败时保留表单内容。
- 布尔值和枚举使用受控组件，不重复转换内部状态码。
- 明确区分清空、`false`、`0` 和未填写，不用 truthy 判断保留值。
- 前端校验不替代后端授权和业务校验。
- 异步结果遵循[请求上下文规则](request-context.md)。
- 字段错误在相关表单处显示，不重复弹出统一请求层已提示的错误。
- 字典提交真实编码，名称使用服务端标签。
- 失效字典值作为禁用历史项回显，可保留或清除，不供新记录选择。
- 附件保存有序文件 ID，取消选择不改表单，解除关联不删文件。
- 上传完成时合并当前字段值，不覆盖上传期间的选择和排序。
- 新密码复用 `NewPasswordFields`，同时提示字符数和 UTF-8 字节上限。
- 密码原值不 trim、不存浏览器；确认密码只在前端比较。
- 个人改密和管理员重置遵循[账号规则](../backend/identity-context.md)。
- 表单布局遵循[模板规则](template-reuse.md)。
