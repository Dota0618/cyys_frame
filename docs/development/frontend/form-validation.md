# 表单模型与输入反馈

- 字段对应 API 命令，按新增、编辑设置初值，只提交可修改字段。
- 提供即时校验，区分清空、false、0 和未填写；失败保留内容，编辑状态用 `setDirty` 维护。
- 字段错误就地显示，请求层已提示的错误不重复弹出；异步处理见[请求规则](request-context.md)。
- 字典提交编码并使用服务端标签，失效值保留为禁用历史项。
- 附件保存有序 ID，上传合并当前值；取消选择和解绑保留原文件。
- 密码用 `NewPasswordFields`，保留原值，确认密码仅前端比较；账号见[身份规则](../backend/identity-context.md)。
- 布局复用[公共预设](template-reuse.md)。
